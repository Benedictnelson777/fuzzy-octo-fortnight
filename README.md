# 🍺 BoozeBuddy - E-Commerce Store for Premium Spirits & Beverages

A modern, user-friendly e-commerce website for selling alcoholic beverages to customers aged 21 and over.

## Features

### 🔒 Age Verification
- Mandatory age verification gate on entry
- Users must confirm they are 21+ years old
- Date of birth validation
- Session-based verification (persists during browsing session)

### 🛍️ Product Catalog
- Wide selection of alcoholic beverages across multiple categories:
  - 🍺 Beer (Craft IPA, Premium Lager, Wheat Beer)
  - 🍷 Wine (Red, White, Rosé)
  - 🥃 Spirits (Vodka, Whiskey, Tequila, Gin)
  - 🍹 Ready-to-Drink Cocktails (Margarita, Mojito, Cosmopolitan, Hard Seltzer)
- Easy category filtering
- Detailed product descriptions and pricing

### 🛒 Shopping Cart
- Add/remove products from cart
- Real-time cart updates
- Running total calculation
- Visual cart icon with item count

### 💳 Checkout Process
- Simple checkout form with customer details
- Delivery address collection
- ID number request for age verification on delivery
- Order confirmation with summary

### 📱 Responsive Design
- Mobile-friendly interface
- Adapts to different screen sizes
- Modern gradient design aesthetic
- Smooth animations and transitions

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server-side requirements - runs completely in the browser

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Benedictnelson777/fuzzy-octo-fortnight.git
cd fuzzy-octo-fortnight
```

2. Open the application:
   - Simply open `index.html` in your web browser
   - Or use a local server (optional):
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (with http-server package)
   npx http-server
   ```

3. Access the site:
   - Direct file: `file:///path/to/index.html`
   - Local server: `http://localhost:8000`

## Usage

1. **Age Verification**: Enter your date of birth to verify you're 21 or older
2. **Browse Products**: View all products or filter by category
3. **Add to Cart**: Click "Add to Cart" on any product you want to purchase
4. **View Cart**: Click the cart icon to review your selections
5. **Checkout**: Fill out the checkout form with your delivery details
6. **Place Order**: Submit your order and receive confirmation
